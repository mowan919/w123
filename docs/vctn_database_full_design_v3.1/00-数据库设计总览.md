# 00 数据库设计总览

## 1. 技术基线

- PostgreSQL
- BIGINT / Snowflake
- UTC `TIMESTAMPTZ`
- SQLAlchemy 2.x
- Alembic
- Redis 用于会话、在线状态、限流、游客额度、缓存，不作为核心账务数据源
- 不使用 `tenant_id`

## 2. 领域划分

```text
sys_*   系统管理域
biz_*   统一业务用户与业务域
tool_*  Tools 工具域
blog_*  Blog 博客域
```

## 4. 关键关系

```text
sys_user
 ├─ sys_role
 ├─ sys_department
 ├─ sys_session
 └─ sys_audit_log

biz_user
 ├─ biz_user_profile
 ├─ biz_user_login_identity
 ├─ biz_user_session
```

## 5. 删除策略

核心业务数据默认不物理删除：

- sys_user：逻辑删除/禁用
- biz_user：逻辑删除
- tool：逻辑删除
- blog article：状态控制
- ledger：禁止删除
- audit：按保留策略归档/删除，不提供业务层删除接口
