# 03 用户成长中心

## 1. 成长账户

```sql
CREATE TABLE biz_user_growth_account (
    id BIGINT PRIMARY KEY,
    user_id BIGINT NOT NULL UNIQUE,
    total_growth_points BIGINT NOT NULL DEFAULT 0,
    current_level_id BIGINT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 2. 积分账户

```sql
CREATE TABLE biz_user_point_account (
    id BIGINT PRIMARY KEY,
    user_id BIGINT NOT NULL UNIQUE,
    total_earned_points BIGINT NOT NULL DEFAULT 0,
    total_spent_points BIGINT NOT NULL DEFAULT 0,
    balance_points BIGINT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CHECK(total_earned_points >= 0),
    CHECK(total_spent_points >= 0),
    CHECK(balance_points >= 0)
);
```

## 3. 成长规则

```sql
CREATE TABLE biz_growth_rule (
    id BIGINT PRIMARY KEY,
    code VARCHAR(64) NOT NULL UNIQUE,
    name VARCHAR(128) NOT NULL,
    source_type VARCHAR(64) NOT NULL,
    event_type VARCHAR(128) NOT NULL,
    reward_points BIGINT NOT NULL,
    daily_limit BIGINT,
    weekly_limit BIGINT,
    monthly_limit BIGINT,
    cooldown_seconds INTEGER,
    requires_success BOOLEAN NOT NULL DEFAULT TRUE,
    status VARCHAR(32) NOT NULL DEFAULT 'ACTIVE',
    effective_from TIMESTAMPTZ,
    effective_to TIMESTAMPTZ,
    description VARCHAR(500),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 4. 积分规则

结构与成长规则一致，表名 `biz_point_rule`。

## 5. 业务成长事件

```sql
CREATE TABLE biz_growth_event (
    id BIGINT PRIMARY KEY,
    event_id VARCHAR(128) NOT NULL UNIQUE,
    user_id BIGINT NOT NULL,
    source_type VARCHAR(64) NOT NULL,
    source_id VARCHAR(128),
    event_type VARCHAR(128) NOT NULL,
    idempotency_key VARCHAR(255) NOT NULL UNIQUE,
    event_data JSONB,
    processed BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    processed_at TIMESTAMPTZ
);
CREATE INDEX idx_growth_event_user_time
ON biz_growth_event(user_id, created_at);
CREATE INDEX idx_growth_event_type_time
ON biz_growth_event(event_type, created_at);
```

生产环境不得把密码、token、secret、完整代码、SQL、工具输入等敏感业务内容写入 event_data。

## 16. 核心事务

奖励必须：

```text
BEGIN
  锁定账户
  校验事件幂等
  校验规则
  校验周期限制
  写流水
  更新账户
  计算等级
  写等级历史
COMMIT
```

任何一步失败全部回滚。

## 17. 禁止

前端禁止提交：

```text
POST /points/add
```

让用户自行指定 reward。

只能：

```text
业务动作
→ 后端可信事件
→ RuleEngine
→ Ledger
→ Account
```
