# 06 日志审计与字典域

## 1. sys_audit_log

核心字段：

```text
id
trace_id
request_id
operator_type
operator_id
action
resource_type
resource_id
result
reason
before_data
after_data
ip
user_agent
created_at
```

敏感字段必须脱敏。

## 2. sys_security_log

记录：

- 登录失败
- 账号锁定
- MFA
- 权限拒绝
- 异常会话
- 安全策略触发

## 3. sys_access_log

记录 HTTP 访问。

## 4. sys_operation_log

记录业务操作。

## 5. application_log

应用日志可以落文件/日志系统；如需要数据库表，命名与现有日志方案统一。

## 6. Trace

请求头：

```text
X-Trace-ID
X-Request-ID
```

链路：

```text
HTTP
→ Controller
→ Service
→ Repository
→ Audit/Security
```

## 7. 字典

### sys_dict_type

```sql
CREATE TABLE sys_dict_type (
    id BIGINT PRIMARY KEY,
    code VARCHAR(64) NOT NULL UNIQUE,
    name VARCHAR(128) NOT NULL,
    status VARCHAR(32) NOT NULL DEFAULT 'ACTIVE',
    description VARCHAR(500),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### sys_dict_item

```sql
CREATE TABLE sys_dict_item (
    id BIGINT PRIMARY KEY,
    dict_type_id BIGINT NOT NULL,
    value VARCHAR(128) NOT NULL,
    label VARCHAR(255) NOT NULL,
    sort_order INTEGER NOT NULL DEFAULT 0,
    status VARCHAR(32) NOT NULL DEFAULT 'ACTIVE',
    metadata JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 8. 日志保留

```text
Access Log      30 天
Security Log    180 天
Operation Log   180 天
Audit Log       2 年
Application Log 30 天
```

密码和 MFA Secret 永不记录。
