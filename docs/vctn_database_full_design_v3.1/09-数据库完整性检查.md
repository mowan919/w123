## D. V3.1 数据库实现注意

当前 SQL 是完整结构基线，不代表所有生产约束已经冻结。

正式开发必须：

```text
数据库设计
→ 冻结决策
→ Alembic migration
→ SQLAlchemy models
→ Repository
→ Service
→ API
→ Integration Test
→ Migration Test
```

禁止 Agent 根据表名自行创造未冻结业务规则。
