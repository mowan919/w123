# 09 前端动态权限

## 1. 核心要求

“用户能够看哪些页面”必须通过后台管理平台配置。

前端不能硬编码完整权限集合。

## 2. Backend Contract

`GET /api/v1/admin/auth/permissions` 应返回当前用户有效权限，至少能够表达：

- pages
- menus
- buttons
- APIs
- fields
- data scopes
- permission version

## 3. Dynamic Route

前端根据后端配置动态生成允许访问的页面。

禁止：

```text
前端隐藏页面
=
安全
```

真正安全边界仍是后端 API authorization。

## 4. Menu / Page

一个 Menu 可以关联多个 Page。

Menu 负责导航组织。

Page 负责页面访问权限。

## 5. Button

按钮根据 Button Permission 显示/隐藏。

但对应 API 必须再次授权。

## 6. Field

前端根据 Field Permission 处理：

- HIDDEN
- READ_ONLY
- EDITABLE
- VISIBLE

后端应避免在 HIDDEN 字段中无意返回敏感数据。

## 7. Immediate Effect

权限变化立即生效。

缓存必须支持版本变化和失效。
