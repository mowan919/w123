# 02 组织与用户

## 1. Department

支持：

- 树形组织
- 创建
- 修改
- 禁用
- 逻辑删除
- 查询子部门
- 部门管理员范围计算

部门管理员数据范围：

```text
当前部门 + 所有子部门
```

## 2. User

核心属性：

- id
- username
- display_name
- phone
- email
- department_id
- status
- password_changed_at
- failed_login_count
- locked_until
- must_change_password
- created_at
- updated_at
- deleted_at

## 3. 用户状态

建议至少支持：

- ACTIVE
- DISABLED
- LOCKED（锁定状态也可由 lock_until 表达）

## 4. 用户角色

用户可以关联多个角色。

有效权限为所有角色权限并集，并考虑角色继承。

## 5. 删除

用户删除采用：

```text
disable + logical delete
```

删除后不能通过普通查询返回。

## 6. 部门管理员

部门管理员可以创建和管理其数据范围内用户。

不得操作范围外用户。

## 7. 位置/职位

Position 可以作为组织扩展模型；若实现，应与 User 解耦，不得将职位等同于 Role。
