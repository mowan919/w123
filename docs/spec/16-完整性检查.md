## 技术设计待冻结项

以下项目在业务 Spec 中不能被 Agent 擅自当作最终产品决策：

1. V1 具体 MFA Provider
2. Access Token / Refresh Token 精确生命周期
3. Redis Key 精确命名
4. Permission Version 具体实现方式
5. Role inheritance 的最终 SQL 存储细节
6. Field Permission 的最终表结构
7. CUSTOM Data Scope 的最终存储模型
8. 日志分区的最终实现
9. Secret Manager 产品选型
10. Rate Limit 的精确阈值
11. 幂等 Key 的具体策略

这些属于技术设计决策，应在实现相应 Phase 前冻结。

## 一致性要求

任何新增实现不得违反：

- Department Admin = 本部门 + 子部门
- 多角色取并集
- 角色继承 V1 支持
- 权限立即生效
- SUPER_ADMIN 不可被管理员踢
- 用户逻辑删除
- 后端 API 最终授权
- 敏感信息脱敏
