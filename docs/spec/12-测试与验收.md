# 12 测试与验收

## 1. Test Layers

### Unit

测试：

- password policy
- data scope
- permission calculation
- role inheritance
- field permission
- masking
- Snowflake serialization

### Integration

测试：

- login
- user CRUD
- department scope
- role assignment
- API authorization
- session revoke
- MFA lifecycle
- audit

### Security

必须覆盖：

- 越权
- IDOR
- data scope bypass
- API bypass
- SUPER_ADMIN protection
- session revoke bypass
- password brute force
- MFA brute force
- sensitive log leakage

## 2. Permission Matrix

至少：

| Actor | Scope |
|---|---|
| SUPER_ADMIN | 全部正常用户 |
| Department Admin | 本部门 + 子部门 |
| Normal User | 自身授权范围 |
| Multi-role User | 多角色权限并集 |
| Inherited-role User | 包含继承权限 |

## 3. 验收标准

- P0/高危安全问题必须 PASS
- 数据库 migration 必须可执行
- API contract 必须符合规范
- Permission Verification 必须 PASS
- Audit/Trace 必须可追踪

最终状态只能：

```text
PASS
FAIL
BLOCKED
```
