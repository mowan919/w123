# 05 字典与系统参数

## 1. Dictionary

模型：

```text
sys_dict_type
  └── sys_dict_item
```

## 2. sys_dict_type

字段：

- id
- dict_code
- dict_name
- description
- status
- created_at
- updated_at
- deleted_at

## 3. sys_dict_item

字段：

- id
- dict_type_id
- item_label
- item_value
- item_code
- sort_order
- status
- is_default
- description
- created_at
- updated_at
- deleted_at

同一 dict type 下 item_value 必须支持软删除感知的唯一性。

## 4. API

管理：

- GET/POST `/api/v1/admin/dicts`
- GET/PUT/DELETE `/api/v1/admin/dicts/{id}`
- GET/POST `/api/v1/admin/dicts/{id}/items`
- PUT/DELETE `/api/v1/admin/dicts/{id}/items/{itemId}`

公开查询：

- GET `/api/v1/dicts/{dictCode}`

## 5. System Parameter

System Parameter 与 Dictionary 分离。

参数示例：

- session timeout
- login max attempts
- password minimum length
- MFA default policy

参数必须有类型、默认值、状态、描述和审计。
