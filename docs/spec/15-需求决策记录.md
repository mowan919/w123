# 15 需求决策记录

## D-001 部门管理员范围

决定：本部门 + 所有子部门。

## D-002 多角色

决定：用户可拥有多个角色，权限取并集。

## D-003 角色继承

决定：V1 支持。

## D-004 Page/Menu

决定：一个 Menu 可以关联多个 Page。

## D-005 权限生效

决定：立即生效。

## D-006 Session Kick

决定：支持单 Session 与全部 Session。

## D-007 SUPER_ADMIN

决定：其他管理员不能踢 SUPER_ADMIN；仅本人 logout。

## D-008 删除

决定：禁用 + 逻辑删除。

## D-009 Password

决定：

- 12+
- upper/lower/digit/special
- last 5
- 90 days
- 5 failures / 30 min lock
- admin reset → force change

## D-010 MFA

决定：按角色 + 按用户。

优先级：

```text
user > role > system
```

V1 具体 Provider 尚未决定。

## D-011 Log Retention

- Access 30d
- Security 180d
- Operation 180d
- Audit 2y
- Application 30d

## D-012 Masking

- phone `138****1234`
- email `abc***@example.com`
- token first 6 chars
- password never
- MFA Secret never

## D-013 Multi-tenancy

决定：V1 不支持多租户，不使用 tenant_id。

## D-014 Business ID

决定：BIGINT + Snowflake，API JSON 字符串。

## D-015 Authorization

决定：后端 API authorization 是最终安全边界。

## D-016 Dynamic Page

决定：用户可访问哪些页面必须由后台配置，不应硬编码为不可配置规则。
