# 13 运维与部署

## 1. Runtime

组件：

- FastAPI application
- PostgreSQL
- Redis

## 2. Configuration

敏感配置不得硬编码：

- DB password
- Redis password
- signing secret
- encryption key
- MFA encryption key

应通过环境变量或正式 Secret Management 注入。

## 3. Migration

部署顺序：

```text
backup/check
→ alembic upgrade
→ application deploy
→ health check
→ smoke test
```

Migration 必须可审查。

## 4. Health

至少：

- application health
- database health
- redis health

## 5. Logging

生产环境必须：

- 结构化
- 带 trace_id
- 带 request_id
- 脱敏
- 支持 retention

## 6. Monitoring

建议监控：

- request latency
- error rate
- login failure
- lockout
- MFA failure
- Redis availability
- DB connection pool
- migration status
