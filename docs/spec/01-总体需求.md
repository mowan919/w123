# 01 总体需求

## 1. 项目目标

建设一个可配置、可审计、可扩展的后台管理平台，支持组织、用户、角色、权限、认证、Session、MFA、字典、日志和审计。

## 2. 技术栈

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis

## 3. 非目标

V1 不支持多公司/多租户模型，不引入 tenant_id。

## 4. 核心模块

1. 组织管理
2. 用户管理
3. 角色管理
4. 权限管理
5. 登录认证
6. MFA
7. Session/在线用户
8. 字典
9. 系统参数
10. 日志与审计
11. Trace
12. 动态页面/菜单/按钮权限
13. 监控与运维扩展
14. 导入导出任务扩展

## 5. 核心原则

- 后端授权为最终安全边界
- 权限可配置
- 权限变更立即生效
- 审计可追溯
- 敏感信息不泄漏
- 模块可扩展
