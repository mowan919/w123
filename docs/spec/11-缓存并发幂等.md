# 11 缓存、并发与幂等

## 1. Redis

Redis 用于：

- Session 辅助状态
- 权限缓存
- permission version
- rate limit
- 其他短期缓存

具体 Key 命名规范在技术实现阶段冻结。

## 2. Permission Cache

权限修改必须：

1. 更新数据库
2. 更新/递增 permission version
3. 使旧缓存失效
4. 后续请求重新计算

不能要求重新登录才能生效。

## 3. Concurrency

重点保护：

- 用户状态
- 密码失败次数
- Session revoke
- 权限修改
- 角色继承
- 字典唯一值

## 4. Idempotency

适用场景：

- 批量操作
- 导入
- Session revoke all
- 其他可能重复提交的写操作

具体幂等 Key 在实现阶段确定。

## 5. Cache Safety

缓存错误不得导致权限放大。

宁可短暂 cache miss，也不能使用明显过期权限允许越权访问。
