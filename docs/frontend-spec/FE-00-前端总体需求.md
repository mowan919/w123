# FE-00 前端总体需求

## 1. 目标
建设 VCTN 后台管理平台 Web 前端，覆盖认证、组织、用户、角色、权限、Session、审计、Trace、字典、系统参数及动态权限管理。

## 2. 技术栈

| 项目 | 规范 |
|---|---|
| Framework | Vue 3 |
| Language | TypeScript |
| Build | Vite |
| Router | Vue Router |
| State | Pinia |

UI 组件库、HTTP Client、CSS 方案等未冻结项不得由 Agent 擅自决定。

## 3. 前后端职责

### Backend
- 身份认证
- API 鉴权
- 数据范围鉴权
- 字段权限最终裁决
- Session 管理
- 审计与安全日志
- 权限配置

### Frontend
- 登录交互
- 权限加载
- 动态路由
- 动态菜单
- 按钮权限控制
- 字段状态展示
- Session 展示与操作
- 管理页面
- 错误处理

## 4. 权限原则

```text
Backend Permission Configuration
        ↓
Role
        ↓
Page / Menu / Button / API / Field / Data Scope
        ↓
/auth/permissions
        ↓
Pinia Permission Store
        ↓
Dynamic Router + Menu + UI
```

前端任何权限判断均不能代替后端 API Authorization。

## 5. ID
后端 BIGINT ID 通过 JSON 以字符串返回，TypeScript 类型必须使用 string，不得使用 number 承载业务 ID。

## 6. 不在本 Spec 内冻结
- UI 组件库
- Token 生命周期具体数值
- MFA Provider
- Redis Key
- 后端权限版本实现
- 后端 CUSTOM Data Scope 存储方式
