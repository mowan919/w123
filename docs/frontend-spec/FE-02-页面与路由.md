# FE-02 页面与路由

## 1. 原则
业务路由由后端权限动态生成。静态路由仅允许 Login、403、404 及必要系统页面。

## 2. 动态路由

```text
Login → /auth/me → /auth/permissions → Permission Store → Route Generator → router.addRoute → Business Page
```

## 3. Route Meta

```ts
interface RouteMeta {
  title: string
  icon?: string
  permission?: string
  hidden?: boolean
  keepAlive?: boolean
}
```

最终权限字段以后端资源模型为准。

## 4. Router Guard
必须处理未登录、Token 过期、权限未加载、无页面权限、403、404、Logout、被踢下线。

## 5. 清理
Logout 或 Session 失效时清除认证状态、权限 Store、动态路由，然后回 Login。

## 6. 禁止
不得仅靠前端 URL 隐藏实现安全控制。
