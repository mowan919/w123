# FE-04 用户与认证

## 1. 登录

```text
Username + Password
 → POST /auth/login
 → 判断 MFA
 → MFA Verify（如需要）
 → 建立认证状态
 → GET /auth/me
 → GET /auth/permissions
 → 建立动态路由
```

## 2. Token
前端负责获取、携带、Refresh、失效处理、清理；具体生命周期由后端冻结决策决定。

## 3. 401

```text
401 → 单实例 Refresh → 成功重试原请求；失败 Logout
```

必须避免并发请求重复刷新 Token。

## 4. 403
展示无权限页面或提示，不得当成登录失效。

## 5. 被踢
Session 被撤销后，API 失败应清理认证、权限和动态路由，提示 Session 已失效并回 Login。

## 6. Logout
调用后端 Logout 后清理 Access Token、Refresh 状态、authStore、permissionStore、动态路由。

## 7. 密码
不得保存或记录明文密码。创建用户遵循后端 must_change_password=true。
