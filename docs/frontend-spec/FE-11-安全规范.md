# FE-11 安全规范

## 1. 原则
前端是不可信边界，关键安全检查必须由后端完成。

## 2. 禁止
- 源码写 Secret
- 保存明文密码
- 打印 Token
- 打印 MFA Secret
- 打印 password
- 用前端隐藏替代后端鉴权
- 信任 URL 中的权限参数
- 使用 number 承载 BIGINT ID

## 3. XSS
用户输入必须安全处理，禁止不可信 HTML 直接注入。

## 4. 文件
上传、下载遵循后端安全策略，前端不能单独决定权限、大小、类型。

## 5. 错误
生产环境不得暴露 Stack Trace、数据库错误、Secret、内部地址和认证信息。

## 6. Source Map
生产环境 Source Map 策略必须明确，不得暴露敏感源码信息。

## 7. Open Redirect
Return URL 必须限制为允许的站内路径。
