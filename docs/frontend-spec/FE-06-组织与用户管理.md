# FE-06 组织与用户管理

## 1. 部门
部门树、新增、编辑、启用、禁用。

## 2. 用户
列表、详情、新增、编辑、启用、禁用、删除、重置密码、角色分配、Session 管理。

## 3. 用户字段
username、real_name、email、phone、department、status、roles、created_at、updated_at。不得展示 password_hash。

## 4. 数据范围
部门管理员操作范围为自身部门及所有子部门。普通用户仅能看到后端允许的数据。前端不能替代 Scope Authorization。

## 5. 最后一个 SUPER_ADMIN
前端正确展示后端禁止操作结果，不得绕过。

## 6. 删除
后端为逻辑删除，前端按后端状态展示。
