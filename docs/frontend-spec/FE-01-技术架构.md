# FE-01 技术架构

## 1. 技术基线
Vue 3 + TypeScript + Vite + Vue Router + Pinia。

## 2. 推荐目录

```text
frontend/
├── public/
├── src/
│   ├── api/
│   ├── assets/
│   ├── components/
│   ├── layouts/
│   ├── router/
│   ├── stores/
│   ├── types/
│   ├── utils/
│   ├── views/
│   ├── App.vue
│   └── main.ts
├── tests/
├── e2e/
└── package.json
```

## 3. 分层

```text
View → Component → Store/Composable → API Client → Backend
```

View 不得重复实现认证、权限和 API 错误处理。

## 4. Store
至少：
- authStore
- permissionStore
- appStore

按业务需要增加 userStore、departmentStore、roleStore、dictionaryStore、sessionStore。

## 5. TypeScript
启用 strict。业务核心数据禁止使用 any。API DTO、Envelope、权限、分页对象必须类型化。

## 6. 构建
必须支持 typecheck、lint、test、build。具体脚本命名如需调整必须记录 Decision。
