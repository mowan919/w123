# FE-05 角色与权限

## 1. 页面
角色列表、创建、编辑、删除、权限配置、数据范围配置、继承关系展示/配置（按后端能力）。

## 2. 权限
Page、Menu、Button、API、Field、Data Scope。

## 3. Field Permission

```text
VISIBLE
HIDDEN
READ_ONLY
EDITABLE
```

前端行为：
- VISIBLE：显示
- HIDDEN：不显示
- READ_ONLY：显示但不可编辑
- EDITABLE：显示并允许编辑

最终后端必须再次验证字段权限。

## 4. Data Scope
支持 ALL、DEPARTMENT、DEPARTMENT_CHILDREN、SELF、CUSTOM。CUSTOM 持久化由后端 Phase 3 决定，前端不得设计替代模型。

## 5. SUPER_ADMIN
权限由后端决定，前端不得用硬编码绕过普通权限流程。
