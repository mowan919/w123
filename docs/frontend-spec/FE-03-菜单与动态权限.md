# FE-03 菜单与动态权限

## 1. 权限链

```text
User → Role → Role Inheritance → Page → Menu → Button → API → Field → Data Scope
```

## 2. Permission Store
至少维护 pages、menus、buttons、apis、fields、dataScope。

## 3. 统一方法

```ts
hasPagePermission(code: string): boolean
hasMenuPermission(code: string): boolean
hasButtonPermission(code: string): boolean
hasApiPermission(code: string): boolean
getFieldPermission(code: string): FieldPermission
```

## 4. 多角色
后端返回用户最终有效权限集合，前端不得重新实现角色继承算法。

## 5. 权限刷新
权限变更后，通过重新获取权限或既定权限版本机制刷新，不得假定权限永久缓存。

## 6. Button
无权限时隐藏或禁止操作；隐藏不能替代后端 API 拒绝。

## 7. Menu
菜单由后端权限结果生成，不得维护独立的业务权限白名单。
