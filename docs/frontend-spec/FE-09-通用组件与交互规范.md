# FE-09 通用组件与交互规范

## 1. 布局
AppLayout、AppHeader、AppSidebar、AppBreadcrumb、PageContainer。

## 2. 数据组件
SearchForm、DataTable、Pagination、EmptyState、LoadingState、ErrorState。

## 3. 操作
ConfirmDialog、Success/Error Notification、Form Validation。

## 4. 权限组件
PermissionButton、PermissionField。业务页面不重复实现权限判断。

## 5. 状态
统一区分 loading、empty、error、success、disabled。

## 6. 分页
遵循后端冻结的 pagination convention，不在前端重新定义分页语义。
