# FE-12 测试与验收

## 1. TypeScript
必须通过 typecheck，不得存在未解决类型错误。

## 2. Unit
覆盖 authStore、permissionStore、route generator、route guard、API Client、Token refresh、PermissionButton、PermissionField。

## 3. Integration
覆盖 Login→permissions→dynamic routes、Logout→route cleanup、401→refresh、Refresh failure→logout、403→forbidden、permission update→refresh。

## 4. E2E
至少 SUPER_ADMIN、DEPARTMENT_ADMIN、普通用户。

## 5. 核心验收

### 页面权限
无 PAGE 权限：菜单不显示、路由不可正常进入；后端 API 仍为最终兜底。

### 按钮权限
无 BUTTON 权限：按钮不显示；直接 API 必须 403。

### 字段权限
READ_ONLY：显示但不可编辑；EDITABLE：可编辑，但提交由后端再次验证。

### 数据范围
部门管理员只能操作自身部门及子部门；修改前端参数不得越权。

## 6. Build
必须通过 npm run build。
