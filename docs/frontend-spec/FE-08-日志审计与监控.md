# FE-08 日志审计与监控

## 1. 页面
Audit Logs、Security Logs、Operation Logs、Access Logs、Trace 查询、Trace 详情。

## 2. 查询
按后端允许的时间范围、操作人、action、resource_type、resource_id、result、IP、trace_id、request_id 查询。

## 3. 敏感数据
不得展示 password、password_hash、MFA Secret、Refresh Token、完整 Token。手机号、邮箱是否展示真实值遵循后端安全规则。

## 4. Trace
详情至少关联 trace_id、request_id、operator、request/result，以及相关 audit/security/operation records。
